# Hint 2: the pieces

Each piece you need, on its own. Putting them together is up to you.

**The client.** Minimal APIs inject services by type: add a lambda parameter of the generated client's type, next
to `body` and `ct`. The type is the service name from the proto, twice:

```csharp
AuctionService.AuctionServiceClient auction
```

**The request.** A generated message is a plain C# class with PascalCase properties:

```csharp
new PlaceBidRequest { LotId = ..., Bidder = ..., Amount = ... }
```

**The call.** It's awaitable, so your lambda needs `async` in front of it:

```csharp
await auction.PlaceBidAsync(request, deadline: ..., cancellationToken: ct)
```

**The deadline.** gRPC has no default timeout, so without one a call to a vanished server waits forever:

```csharp
deadline: DateTime.UtcNow.AddSeconds(2)
```

**The response.** The browser gets JSON, not protobuf. `AuctionDto.From(...)` turns an `Auction` message into it.

**The errors.** A rejected bid arrives as an `RpcException`. `ex.ToProblem()` (in `GrpcErrors.cs`) turns it into
an HTTP error with the server's reason.

**The usings.** Your file starts with none. The generated types live in `Dignitas.Auction.V1`, and
`RpcException` in `Grpc.Core`: `AuctionEndpoints.cs` has both at the top.
